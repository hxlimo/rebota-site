# Site public de Rebota

Les conditions d'utilisation et la politique de confidentialité de l'application
**Rebota** — trouver des joueurs de padel de son niveau, en Algérie.

Apple et Google exigent une adresse web publique pour ces deux textes : un écran
dans l'application ne suffit pas. Ce dépôt ne contient que ces pages.

Elles sont **générées**, jamais écrites ici : la source unique est
`src/content/legal.ts` dans le dépôt de l'application, que l'app affiche aussi.
Deux textes qui divergeraient — l'un dans l'app, l'autre sur le site — seraient
pires que pas de texte du tout. Pour les mettre à jour : `npm run legal` côté
application, puis recopier le dossier `site/` ici.
